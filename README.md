**Staff Technical Lead · Cloud Architect · AI Systems Engineer** — Peru 🇵🇪

## 🧭 What I work on

- **Legacy → modern platform.** Strangler-style migration of a monolith (PHP/Laravel + MySQL) to Python/FastAPI services, with data modeling, contracts and a migration path that keeps production running.
- **Cloud & edge.** GCP (Cloud Run, Cloud SQL, Load Balancing, Memorystore), AWS, and Cloudflare Workers/D1/R2 — with infra and gateway config versioned in Git and deployed through PRs.
- **Security engineering.** Incident response, hardening, identity (OIDC IdP + RBAC at the edge), 2FA rollout and access governance across teams.
- **Payments.** Multi-country, multi-gateway card flows (Izipay, Culqi, Kushki) and an internal merchant-of-record payments service.
- **AI agents in production.** Conversational booking agents, and read-only operations agents that watch logs and infra and file findings as issues.
- **Engineering culture.** Engineering guidelines, code review standards and technical hiring exercises.
